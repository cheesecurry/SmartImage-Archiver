# SmartImage Archiver

**SSIM（構造的類似性）に基づき、画質を維持しながら画像を最適圧縮する次世代アーカイブ最適化ツール**

SmartImage Archiverは、画像アーカイブ（ZIP, RAR, 7z等）内の画像を、高効率な次世代フォーマット（AVIFまたはWebP）に変換することで、視覚的な品質を保ったままファイルサイズを劇的に削減するツールです。

## 🌟 概要

従来の圧縮ソフトは「ファイルサイズを小さくすること」だけを目的としていましたが、本ツールは**「見た目の綺麗さを維持しつつ、いかに小さくするか」**を数学的に追求します。

**SSIM (Structural Similarity Index Measure)** という指標を用いることで、「人間が目で見た時に、圧縮前と後で違いが分からない（または許容範囲内である）」レベルの画質を保証しながら、最適な圧縮率を自動的に探し出します。

## ✨ 主な機能

-   🔍 **画質保証 (SSIMベース)**: 指定したSSIMしきい値（例: 90%）を下回らない範囲で、最大限の圧縮を行います。
-   🚀 **インテリジェントな二分探索**: 圧縮率と画質のバランスを、二分探索アルゴリズムを用いて高速に自動探索します。
-   🖼️ **次世代フォーマット対応**: **AVIF** および **WebP** へ変換。従来のJPEG/PNGよりも圧倒的な圧縮率を実現します。
-   ⚡ **マルチスレッド高速処理**: CPUの全コアを活用し、大量の画像も高速に処理します。
-   📦 **多彩なアーカイブ形式に対応**: `.zip`, `.rar`, `.7z`, `.cbz`, `.cbr`, `.cb7` をサポート。
-   🖱️ **Windows 右クリックメニュー対応**: インストール後は、ファイルを右クリックするだけで簡単に最適化が可能です。

## 🚀 インストール方法

### Windowsユーザー（推奨）
1. [Releases](https://github.com/cheesecurry/SmartImage-Archiver/releases) ページから最新の `SmartImageArchiverSetup.exe` をダウンロードします。
2. インストーラーを実行してインストールを完了させてください。
3. インストール後は、最適化したいアーカイブファイルを**右クリック**するだけで使用できます。

### 開発者向け (Source Build)
Python 3.12 が必要です。
```bash
git clone https://github.com/cheesecurry/SmartImage-Archiver/yourrepo.git
cd yourrepo
pip install -r requirements.txt
python SmartImage_Archiver.py [入力ファイルパス]
```

## 🛠 使い方

### 1. 右クリックメニューから使用する（推奨）
インストーラーでインストールした場合、ファイルに対して以下の操作が可能です。

- **最適化 (Optimize)**: ツールが AVIF と WebP を比較し、**画質を維持したまま最もサイズが小さくなる方を自動選択**します。
- **AVIFで最適化**: AVIF形式での圧縮を強制します。
- **WEBPで最適化**: WebP形式での圧縮を強制します。

### 2. コマンドライン (CLI) から使用する
高度な設定を行いたい場合は、コマンドラインから引数を直接指定できます。
```bash
SmartImageArchiver.exe [入力ファイル] --ssim 95 --format avif --workers 4
```

## 📤 出力仕様

本ツールは、元のデータを保護するために**非破壊的**な設計になっています。

- **元のファイル**: 読み込み時も、処理中も、**一切変更・上書きされません。**
- **出力ファイル**: 処理が完了すると、元のファイルと同じフォルダに、ファイル名に `-convert` を付けた新しいファイル（例: `sample-convert.zip`）が生成されます。
- **上書きについて**: 同じソースファイルに対して再度実行した場合、**既存の `-convert` ファイルは上書きされます。**

## ⚙️ 設定方法 (`config.json`)

**インストーラー版（右クリックメニュー）を使用する場合、実行時の引数は固定されています。**
そのため、**「画質のしきい値」**や**「使用するCPUコア数」**を変更したい場合は、実行ファイル（`SmartImageArchiver.exe`）と同じフォルダに `config.json` という名前のファイルを作成し、以下の形式で記述してください。

### 設定ファイルの例 (`config.json`)
```json
{
  "ssim": 95.0,
  "workers": 4
}
```

### 設定項目の説明

| 項目 | 型 | デフォルト値 | 説明 |
| :--- | :--- | :--- | :--- |
| `ssim` | float | `90.0` | **目標とする画質（0-100）**。数値が高いほど高画質（ファイルサイズは大きくなる）になります。`95.0` 以上に設定すると、非常に高品質な結果が得られます。 |
| `workers` | int | `CPUの半分` | **使用するCPUコア数**。PCのスペックに合わせて調整してください。制限しない場合は、システムの安定性を考慮してCPUの半分のコア数が自動的に割り当てられます。 |

## 🧠 技術的な仕組み

1. **展開**: アーカイブを一時ディレクトリに展開します。
2. **二分探索 (Binary Search)**: 各画像に対して、画質（SSIM）を指標とした二分探索を実行し、指定されたSSIM値をクリアできる「最も低い品質設定」を特定します。
3. **比較**: AVIFとWebPの双方でテストを行い、SSIM条件を満たしつつ、よりサイズが小さくなるフォーマットを選択します。
4. **再圧縮・出力**: 最適化された画像を集め、元のファイル名に `-convert.zip` を付与した新しいアーカイブとして出力します。
